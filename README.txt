チェス五目 Web試作版（2〜4人対応・色別接続矢印）

更新内容:
- 2〜4人を選択して同じ端末で交互にプレイ可能
- 色は青・赤・黒・白（プレイヤー1〜4）
- 勝利メッセージに勝者の色とプレイヤー名を表示
- 接続矢印は各プレイヤーの色で表示し、接続元から接続先へ矢印を描画
- 「接続候補」と「駒間の接続矢印」は個別にON/OFF可能

アップロード:
GitHubのリポジトリ内の index.html を、このファイルで置き換えてコミットしてください。

注意:
オンライン対戦はFirebase未設定のため未実装です。4人対応はローカル（同じ端末）対戦です。
勝利条件の基本ルールは維持しています。複数人の場合、いずれかの相手プレイヤーが長距離ボーナスを持つと、他のプレイヤーの必要経路駒数を9個にします。実機で動作確認してください。
