チェス五目 Web版 試作

ファイル
- index.html : スマホ/PC向けのブラウザ版

使い方
1. index.html をChrome / Edge / Safariで開くとローカル対戦できます。
2. 「能力あり/なし」「ナイト」「長距離ボーナス」「分岐制限」を選び、「設定で対局開始」を押します。
3. 空きマスをタップして駒を選んで配置します。全ての手持ち駒を置き終えた後は、自分の駒を選択して空きマスをタップすると移動できます。

注意
- この版はブラウザで動作する試作です。VBAは不要です。
- 15x15盤、駒の基本接続、同種駒の直接接続禁止、7/9個の経路勝利、能力なしの5連続勝利を実装しています。
- 長距離ボーナスは、長距離接続（10マス超）を持つ適格なルーク/ビショップ/クイーンを判定し、相手の勝利経路条件を9個にします。分岐制限ONでは対象駒の接続次数を1に限定しています。
- オンライン対戦UIは選択肢として表示していますが、現状ネットワーク通信は未実装です。別端末間のオンライン対戦には、Firebase Realtime Database等のバックエンド設定と認証/同期処理を追加する必要があります。現段階ではオンラインを選ぶとローカル対戦に切り替わります。
- 試作版につき、実際のExcel VBA版と完全一致するかの検証は未完了です。特に特殊な長距離ボーナス条件と移動時の勝敗判定は十分に対局テストしてください。
