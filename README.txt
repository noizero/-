チェス五目 Web版（2〜4人対応・大画面・接続経路表示）

使い方：
1. GitHub Pagesで公開しているリポジトリの index.html を、このフォルダ内の index.html に置き換えます。
2. GitHubで変更を Commit changes します。
3. 公開ページを Ctrl+F5 で再読み込みします。

更新点：
・盤面を画面幅に合わせて大きく表示します。
・プレイヤー色の表記を色付きにしました。
・「接続経路の状況」をオンにすると、各プレイヤーの確認できた最長の有向接続経路、接続駒数、駒の種類と座標を表示します。
・接続候補、接続矢印、接続経路状況はそれぞれ個別に表示／非表示を切り替えられます。

注意：
・同じ端末でのローカル対戦版です。オンライン対戦にはFirebase設定が必要です。
・接続経路の状況は探索数に上限を設けているため、盤上の駒や接続が多い場合は「確認できた範囲で最長」と表示する場合があります。
